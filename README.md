# Genome-wide donor–recipient mismatch analyses

This repository provides two complementary tools for kidney-transplant genetic
mismatch analyses:

| Script | Purpose |
|---|---|
| `compute_gw_mm.sh` | Create donor–recipient mismatch VCFs from a single VCF containing donor and recipient genotypes. |
| `cox_mm.R` | Illustrate time-to-event association testing when separate recipient and donor dosage tables are available for a selected list of SNPs. |

These are separate entry points. `cox_mm.R` does not require or directly read
the VCF/PGEN output generated by `compute_gw_mm.sh`.

## Requirements

### `compute_gw_mm.sh`

- Slurm
- `bcftools` and `plink2`
- Python 3
- `awk` and standard Unix command-line tools

### `cox_mm.R`

- R
- the R package `survival`

## Create genome-wide mismatch VCFs

Use `compute_gw_mm.sh` when donor and recipient genotypes are stored together
in one indexed, multi-chromosome VCF. The script runs one Slurm array task per
autosome and creates a VCF in which each sample represents a donor–recipient
pair and each dosage represents their mismatch count.

### Inputs

- `--vcf`: one bgzip-compressed and indexed VCF containing chromosomes 1–22;
- `--pairs`: a two-column, whitespace-delimited file containing recipient ID
  followed by donor ID, without a header; and
- `--outdir`: output directory.

Both members of every retained pair must be present as samples in the VCF.
Repeated recipients or donors across different pairs are supported.

### Run

```bash
sbatch --array=1-22 compute_gw_mm.sh \
  --vcf /path/to/donor_recipient_genotypes.vcf.gz \
  --pairs /path/to/recipient_donor_pairs.txt \
  --outdir /path/to/mismatch_output
```

Specifying `--array=1-22` is currently required because the script's embedded
Slurm default selects chromosome 22 only.

### Mismatch definition

For donor ALT dosage `x` and recipient ALT dosage `y`, the mismatch count is:

```text
abs(y - 1) * abs(x - y)
```

The result is 0, 1, or 2 copies of a donor allele that the recipient does not
carry. A heterozygous recipient has both REF and ALT, so the mismatch is zero
regardless of donor genotype.

### Outputs

The output directory contains:

- `MM/chr<N>.vcf.gz` and its index: mismatch dosages for chromosome `N`;
- `MM/chr<N>.pgen`, `.pvar`, and `.psam`: the same data in PLINK 2 format; and
- `PAIRS/full_pairs.txt`: retained recipient–donor pairs.

Pair sample names in the mismatch files use `recipient_donor`.

## Illustrative time-to-event association analysis

Use `cox_mm.R` when recipient and donor dosage data are already available for a
given list of SNPs. The script matches donor–recipient pairs, derives a binary
mismatch for each SNP, and fits an adjusted Cox proportional-hazards model for
each mismatch.

### Dosage inputs

The recipient and donor dosage tables must contain the same variants, in the
same order, with these named columns:

```text
CHROM  POS  ID  REF  ALT
```

All remaining columns contain dosages for donor–recipient pair IDs. Their
column names must match the phenotype pair-ID column (`ID` by default).
Dosages are rounded to 0, 1, or 2 before mismatches are calculated.

### Phenotype input

The phenotype table must contain:

- a donor–recipient pair ID;
- a follow-up time;
- a binary event indicator coded 0/1; and
- the requested model covariates.

By default, the script analyzes `FAILURE`, uses `TIME_FAILURE` for follow-up,
matches pairs through `ID`, and runs the `epi` covariate model. The legacy
62-column phenotype layout is detected automatically when the expected headers
are absent, but the input must still contain a header row.

### Run with the original model defaults

```bash
Rscript cox_mm.R \
  --pheno /path/to/pheno-epi.txt \
  --recipient-dosage /path/to/recipients.dosage.failure.txt \
  --donor-dosage /path/to/donors.dosage.failure.txt \
  --output /path/to/results/FAILURE.hla-epi.txt \
  --event FAILURE \
  --hla epi \
  --cores 4
```

In `epi` mode, phenotype rows missing the column selected by `--epi-col`
(`EPI` by default) are removed. The default model adjusts for recipient and
donor PCs 1–4, transplant year, rank, recipient sex and age, donor type and
sex, epitopic mismatch, and time-varying donor age.

### Run with custom outcome fields and covariates

```bash
Rscript cox_mm.R \
  --pheno /path/to/pheno.tsv \
  --recipient-dosage /path/to/recipient_selected_snps.tsv \
  --donor-dosage /path/to/donor_selected_snps.tsv \
  --output /path/to/results.tsv \
  --event-col graft_failure \
  --time-col follow_up_days \
  --pair-id-col pair_id \
  --hla none \
  --covariates 'PC1_R,PC2_R,PC1_D,PC2_D,recipient_age,donor_age'
```

Run `Rscript cox_mm.R --help` to see all arguments.

### Cox mismatch definition

The R example uses a binary rather than copy-count mismatch:

```text
min(abs((recipient - donor) * (recipient != 1)), 1)
```

Thus the Cox coefficient compares pairs carrying a donor-derived mismatch with
pairs not carrying that mismatch at the SNP.

### Output

The tab-delimited result has the following columns:

```text
CHROM  POS  ID  REF  ALT  COEF  SE.COEF  P  FREQ
```

- `COEF`: log hazard ratio for carrying the binary mismatch;
- `SE.COEF`: standard error of `COEF`;
- `P`: two-sided Wald-test p-value; and
- `FREQ`: proportion of analyzed donor–recipient pairs carrying the mismatch.

Failed or invariant SNP models are retained with `NA` association statistics.
`FREQ` is a pair-level mismatch-carrier frequency, not an effect-allele
frequency. Likewise, a mismatch can represent introduced ALT in some pairs and
introduced REF in others, so the output is not a conventional allele-dosage
GWAS summary-statistics file.
